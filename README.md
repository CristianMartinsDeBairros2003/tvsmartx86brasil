# TV Smart x86 Brasil OS
Este projeto é um conceito de uma plataforma de smart TV para computadores 64 bits, baseada no Linux, e que poderia reproduzir o mesmo conceito de uma TV com acesso a Internet, mas rodando nos computadores em geral para código aberto e avançado. Nossa distribuição, que irá ser chamada de "TV Smart x86 Brasil", irá ser baseada no Linux Ubuntu, para usufruir ao mesmo tempo dos recursos avançados do Ubuntu em geral.
